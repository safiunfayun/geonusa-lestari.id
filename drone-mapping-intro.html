Training Program

Drone Mapping Introduction

Program pengenalan untuk memahami konsep pemetaan UAV, perencanaan misi, kebutuhan ground control, pengambilan data, serta alur pengolahan hingga output pemetaan.

IntroductionUAVMapping Workflow
Learning Outcomes

Apa yang akan dipelajari?

Mission PlanningMemahami prinsip dasar flight planning.
Field PreparationMemahami kebutuhan area, GCP, cuaca, dan keamanan.
Data CaptureMemahami overlap, altitude, dan kualitas foto.
Mapping OutputMengenali orthomosaic, DSM, dan output dasar.
Syllabus

Struktur materi.

Module 01 — UAV Mapping OverviewKonsep fotogrametri dan pemetaan drone.
Module 02 — EquipmentDrone, controller, battery, target, dan accessories.
Module 03 — Flight PlanningArea, altitude, overlap, route, dan safety.
Module 04 — Ground ControlPengenalan GCP dan check point.
Module 05 — Data CaptureChecklist dan quality control lapangan.
Module 06 — Processing WorkflowAlignment, point cloud, DSM, orthomosaic.
Module 07 — Quality CheckCoverage, blur, gaps, dan accuracy concept.
Module 08 — Mapping OutputExport dan penggunaan hasil pada GIS.

Training Format

  • Concept explanation
  • Guided practice
  • Exercise dataset
  • Discussion & Q&A
  • Mini project / practical assignment

Target Participants

Mahasiswa, fresh graduate, staf teknis, surveyor pemula, anggota tim proyek, atau peserta yang ingin membangun kompetensi dasar.
